# 👻 The DeadCode Whisperer

*An offline, air-gapped terminal séance that channels the spirit of the ALGOL programming language.*

Built for the **DEV Community Hacktoberfest Open-Source AI Challenge (Week 4: Ghost in the Machine)**.

## 📜 Overview
The DeadCode Whisperer is a local, privacy-first AI application that resurrects the ghosts of legacy computing. Instead of a helpful assistant, users interact with a spectral entity from the digital void that speaks in formal, archaic tones, laments the loss of structural blocks, and views modern syntax as chaotic. 

The project strictly utilizes open-weight models running locally to ensure the "ghost" is permanently trapped on the machine, requiring zero internet connection or corporate API calls.

## ✨ Features
* **Offline Inference:** Runs locally via Ollama, ensuring user queries never leave the machine.
* **Retro-Terminal UI:** Custom Streamlit CSS creates a dark, phosphor-green immersive aesthetic.
* **Legacy Persona:** Heavily prompt-engineered to emulate the attitudes and metaphors of 1960s mainframe computing.

## 🛠️ Prerequisites
Before running this project, ensure you have the following installed:
* [Python 3.8+](https://www.python.org/downloads/)
* [Ollama](https://ollama.com/) (Running in the background)
